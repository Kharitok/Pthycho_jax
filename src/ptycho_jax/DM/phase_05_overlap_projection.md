# Phase 5: Overlap projection P_O (object, probe modes, per-position weights)

## Purpose

Project arbitrary exit waves psi onto the overlap set: find (P, O, a) such that `a_jk * S_j P_k * E_j O` is closest to psi in least squares. This is the core new piece. It is an **approximate projection**: a few alternating block solves, each an exact minimizer over its own block with the others fixed, **warm-started from the persistent (P, O, a) in the DM state** (never from scratch).

## Function

```
overlap_projection(psi, state, data_geom, cfg, gates) -> (psi_O, probe, obj, a)
```

- `gates` are **traced** values: `update_probe` (bool), `weight_mode` (int32: 0 = fixed, 1 = global, 2 = per_position), `fix_gauge` (bool).
- `psi_O = a * S P * E O` computed from the final (P, O, a).
- `n_inner` (static) inner iterations via `lax.fori_loop`.

## Inner iteration (in this order)

### 1. Object block: `solve_object`

```
N   = A_O_H(psi)                          # numerator, canvas shape
D   = D_O                                 # denominator, canvas shape
O   = (N + alpha_O * O_old) / (D + alpha_O)
```

`alpha_O` is absolute (relative value times `max(D_O)`). The damping pulls **toward the previous estimate**, so unscanned canvas regions keep their previous value instead of decaying to zero.

### 2. Probe block: `solve_probe` (gated by `update_probe`)

```
N_k = A_P_H(psi)_k
P_k = (N_k + alpha_P * P_old_k) / (D_P_k + alpha_P)
```

Where `D_P_k` is about 0 for an entire mode (the mode has no weight anywhere), keep the previous `P_k`.

Optional solver variant (`cfg.probe_solver = "cg"`, static): solve `(A_P^H A_P + alpha_P I) P = A_P^H psi + alpha_P P_old` matrix-free with `jax.scipy.sparse.linalg.cg`, warm-started from the diagonal solution, 3 to 5 iterations. Use it when check C3.8 showed a poor diagonal approximation (sub-pixel positions). Verify that the CG routine handles complex Hermitian positive-definite operators correctly in the installed JAX version (test C5.9).

### 3. Mode renormalization

For each mode k: `nu_k = norm(P_k)`, then `P_k <- P_k / nu_k` and `a_jk <- a_jk * nu_k` for all j. The product `a * P` is unchanged, so `psi_O` is unchanged.

### 4. Weight block: `solve_weights` (according to `weight_mode`)

With `u_jk = S_j P_k * E_j O` and `<u, psi> = sum_q conj(u) * psi` over the (Ny, Nx) pixels:

- **per_position** (mode 2): `a_jk = max(0, Re<u_jk, psi_jk>) / (norm(u_jk)^2 + eps_w)`. This is the exact constrained least-squares solution for a real, non-negative scalar.
- **global** (mode 1): `a_k = max(0, sum_j Re<u_jk, psi_jk>) / (sum_j norm(u_jk)^2 + eps_w)`, broadcast over j.
- **fixed** (mode 0): no change.
- Optional blend: `a <- (1 - lambda) * a_global + lambda * a_fit` (`cfg.weight_blend`, default lambda = 1 means no blending).

### 5. Object gauge (gated by `fix_gauge`)

Apply the object scale and phase normalization of Phase 6 (with exact compensation in `a` and `P`, so `psi_O` is unchanged).

## Outputs

- `psi_O`: the projected exit waves.
- Updated `probe`, `obj`, `a` (these are the DM state's current estimates and what is handed to optax).

## Checks (the most important tests of the whole plan)

Unless stated otherwise: float64, **integer positions**, `alpha` set very small (relative 1e-12) so the block solves are essentially exact.

| ID | Check | Tolerance |
|---|---|---|
| C5.1 | **Fixed point:** starting from psi generated by the stage model from truth (P*, O*, a*), `overlap_projection` returns psi unchanged and (P, O, a) equal the truth up to gauge (compare via the gauge-invariant products and intensities) | 1e-10 |
| C5.2 | **Monotone residual:** the plain residual `norm(psi - psi_O_current)^2` is non-increasing across each block update within the inner loop (renormalization and gauge steps leave it unchanged) | non-increase beyond 1e-12 relative is a failure |
| C5.3 | **AD cross-check, object:** after `solve_object` with its alpha, `jax.grad` of `0.5*norm(psi - A_O O)^2 + 0.5*alpha_O*norm(O - O_old)^2` at the new O is about 0, relative to the gradient at O_old (use a perturbed O_old so that reference gradient is non-zero) | ratio < 1e-8 |
| C5.4 | **AD cross-check, probe:** same construction per mode with `alpha_P` | ratio < 1e-8 |
| C5.5 | **AD cross-check, weights (KKT):** for `g = d/da [0.5*norm(psi_jk - a*u_jk)^2]` obtained with `jax.grad`: where `a > 0`, `abs(g)` is about 0; where `a = 0`, `g >= -tol` | 1e-8 |
| C5.6 | **Perturbed start:** start from truth plus 10% noise on P, O and a, run 20 inner iterations on the true-model psi (probe and weights enabled); converges to the truth up to gauge | object and probe relative error < 1e-6 (noise-free) |
| C5.7 | **Weights non-negative** always; clamping does not produce NaN when `u_jk` is about 0 | exact |
| C5.8 | **Gates:** with `update_probe = False` the probe is bit-identical before and after; with `weight_mode = 0` the weights are bit-identical | exact |
| C5.9 | **CG probe solver** (if implemented): for sub-pixel positions the CG result satisfies the stationarity condition of the exact least-squares probe problem (AD cross-check as in C5.4) to 1e-6, and is at least as good as the diagonal solution in residual | 1e-6 |
| C5.10 | **Sub-pixel behaviour** (informational): with sub-pixel positions the diagonal probe update's residual is non-increasing within a looser tolerance; report the violation magnitude | reported |
| C5.11 | **Symmetry** (informational): with K = 2 and identical modes the modes stay identical. This documents why Phase 7 must break the symmetry | reported |
| C5.12 | Chunked evaluation equals unchunked (all sums are accumulated through a carry) | tol64 |
| C5.13 | Compiles once for all gate values (gates traced, no retracing) | trace count = 1 |

## Gate

C5.1 to C5.8, C5.12, C5.13 pass, and C5.9 if the CG solver exists. The sub-pixel results (C5.10) are recorded.

## Pitfalls

- Pulling toward zero instead of toward the previous estimate (the unscanned region collapses).
- Non-warm-started solves (the state is persistent; a cold start every iteration loses the accumulated estimate).
- Skipping the clamp on weights; negative `a` flips the sign of a mode's contribution and destroys the model.
- Treating a non-zero AD gradient in C5.3 and C5.4 as a bug when `alpha` is large: the stationarity condition includes the damping term as written above.
